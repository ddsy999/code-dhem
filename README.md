# DHEM

Reproduction code for "Dual Homotopy Framework for Constrained EM Algorithm".

## Files

- `DHEM.R` — main script that reproduces all results (figures, tables) in the paper
- `DHEM_functions.R` — functions used to fit the GMM/WMM/ZIP models

## Folders

- `DATA/` — input data and simulation caches
- `figure/` — generated figures
- `table/` — generated result tables
